A deterministic Python + Pillow renderer that draws one open passport spread for the invented Republic of Ostravia: a bilingual data page with portrait, ghost image, signature and an MRZ whose ICAO check digits are computed in code, facing a visas page whose twelve entry/exit stamps and Kharadian visa sticker tell one consistent, date-checked travel history.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
